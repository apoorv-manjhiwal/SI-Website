# SI Systems

Responsive IT systems integrator website built with dependency-free HTML, CSS and JavaScript. Includes fixed navigation, an animated network globe, service cards, a technology vendor ecosystem, company information, legal dialogs and a local project brief download. Respects reduced-motion preferences.

## Run

```sh
cd /workspace/SI-Website
python3 -m http.server 8000 --bind 0.0.0.0
```

No package installation or build is required. Python 3 is available in the cloud environment. Deploy `index.html`, `styles.css`, and `script.js` to any static host.

## Before publication

Replace the working name SI Systems, draft company copy, contact placeholders, company registration details and legal notices with verified information. Vendor names are illustrative; confirm actual partnerships and authorizations before claiming them. Contact briefs download locally and are not sent to a server. Connect a backend or form service if email delivery is required.
